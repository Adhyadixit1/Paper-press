# Paper & Press

Paper & Press is a Next.js wholesale paper-packaging storefront for Indian businesses. It includes product and industry collections, configurable packaging categories, custom-size pricing guidance, quote requests, and WhatsApp ordering.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm run start
```

## Vercel deployment

Import the GitHub repository into Vercel. The project uses the standard Next.js build and requires no custom build or output-directory settings.

Set `NEXT_PUBLIC_SITE_URL` to the final production URL if you use a custom domain. Vercel's production URL is used automatically when the variable is omitted.
